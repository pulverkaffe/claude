# Welcome!

This is an example Markdown post that will be imported into beehiiv as a draft.

## Front Matter

The metadata at the top (between the `---` markers) is called front matter. It includes:

- **title**: The post title
- **subtitle**: An optional subtitle
- **content_tags**: Tags for organizing your content

## Markdown Content

Everything below the front matter is your post content. You can use:

- **Bold text** and *italic text*
- [Links to websites](https://www.example.com)
- Lists (like this one!)

### Code Blocks

```python
def hello_world():
    print("Hello from beehiiv!")
```

### Images

You can include images using standard Markdown syntax:

```markdown
![Alt text](https://example.com/image.jpg)
```

**Note**: Images must be hosted externally. Make sure to use full URLs.

## Ready to Import?

1. Replace this file with your own content
2. Add more `.md` files to the `posts` directory
3. Run the import script: `python beehiiv_import.py`

All posts will be created as **drafts** in beehiiv, so you can review and edit them before publishing!
